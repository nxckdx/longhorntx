The lhtx agent runs in {{ .Release.Namespace }} and keeps its lease in {{ .Values.leaseNamespace | default .Values.longhornNamespace }}.
{{- if and .Values.leaseNamespace (ne .Values.leaseNamespace .Values.longhornNamespace) (not .Values.rbac.leaseListForAllUsers) }}
lhtx finds that lease by label only if users may list leases in all namespaces
(rbac.leaseListForAllUsers=true, or grant it yourself).
{{- end }}

Check it with:  lhtx -n {{ .Values.longhornNamespace }} agent status

{{- if .Values.rw }}
Read-write (rw: true): lhtx freeze / unfreeze / switch (and Z, w in the TUI)
now hand their work to the agent.
{{- else }}
Read-only (rw: false): the agent keeps digests, history, metrics and filters
diag logs; it refuses Freezes and Switches – lhtx does them itself. Set
rw: true to let the agent carry them out.
{{- end }}
